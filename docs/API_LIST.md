# API / Route List

| Method | Route                     | Purpose                         |
| ------ | ------------------------- | ------------------------------- |
| GET    | /                         | Home / application landing page |
| GET    | /sponsorships/dashboard   | Summary dashboard               |
| GET    | /sponsorships             | List/search sponsorships        |
| GET    | /sponsorships/new         | New sponsorship form            |
| POST   | /sponsorships/save        | Create or update sponsorship    |
| GET    | /sponsorships/edit/{id}   | Edit sponsorship                |
| GET    | /sponsorships/delete/{id} | Delete sponsorship              |
| POST   | /sponsorships/{id}/status | Change sponsorship status       |

The login, user-management and health-check routes remain planned backlog items.
