# Planned API / Route List

| Method | Route | Purpose |
|---|---|---|

| GET | /login | Login page |
| POST | /login | Authenticate user |
| GET | /dashboard | Summary dashboard |
| GET | /sponsorships | List/search sponsorships |

| GET | /sponsorships/{id} | View sponsorship |
| GET | /sponsorships/{id}/edit | Edit sponsorship |
| POST | /sponsorships/{id} | Update sponsorship |
| POST | /sponsorships/{id}/status | Change sponsorship status |
| GET | /admin/users | Manage users |
| POST | /admin/users | Create user |
| GET | /health | Deployment health check |
